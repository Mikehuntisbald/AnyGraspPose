# V42 complete CAD correspondence decoder

Status: implementation and24 targeted tests passed; bounded100-update joint trial launched. Accurate geometry remains unproven. No default-model change.

Prior evidence: V23's56x56 soft mean over256 CAD anchors plus free XYZ offset failed its frozen-backbone500-step pilot. V41's corrected supervision did not improve joint geometry over matched V40. The new trial therefore does not repeat soft coordinate averaging.

V42 uses the immutable8192-point CAD cache, including frozen Utonia descriptors, texture colors and normals. Current estimated camera geometry and measured-depth residuals are computed for every point. Only JEPA/DPT dense features generate queries. A learned descriptor/geometry key and the detached old DPT canonical estimate as a soft geometric prior rank the complete point bank. The actual forward XYZ is a selected CAD point. A local eight-candidate straight-through surrogate supplies geometry gradients; it does not change forward values. Original DPT depth and validity outputs remain. Empty CAD falls back exactly to DPT. The old2D flow head remains loaded/frozen only for weight provenance and has no active prediction/loss path.

This ensures sampled-surface membership, not globally correct correspondence or rigid consistency. It does not certify physical accuracy, remove the point sampling resolution limit, or guarantee correct normals at argmax discontinuities. The global correspondence objective is required to test actual identity learning.

Teacher-only correspondence loss: sample at most256 eligible pixels per real/proxy/visible source per image; target canonical CAD coordinates select8 nearest available CAD points. A Gaussian with sigma0.01d defines soft labels over those local points. Cross entropy normalizes over the full bank; masks are entirely teacher-owned. Real/proxy/visible strata are separately normalized with weights1/0.5/0.5. No per-pixel symmetry remapping occurs. The CE weight is1 alongside the existing canonical geometry and real-depth objectives; FP32 label construction and V41 quality masks remain. There is no pose or DINO feature loss, and history stays disabled.

The trial uses the same V38 raw200 parent and full-window samples as V41, seed42,32 distinct observations/64 paired pose hypotheses per update, eight H20s and100 updates. Parent tensors are verified exact; only `cad_atlas_decoder` is randomly initialized with seed84. Optimizer is reset; new atlas parameters use the existing transport learning-rate group1e-3. It executes2 updates, fixed64-record probe0 in corrupted/clean conditions, strict resume to100, then identical probes. Evaluation retains original unfiltered labels.

Tests cover actual-point output, unchanged depth, missing-CAD/NaN fallback, positive query/key/input gradients, and learning a known16-way point mapping, plus existing supervision/geometry regressions. The two-step full-model startup additionally verifies gradients in the JEPA projection, DPT output and both atlas query and descriptor projections on all8 ranks.

Runtime `/tmp/dexycb_cad_atlas_v42`; artifact root `/mnt/why/dexycb_lip/unified_jepa_20260921/cad_atlas_v42`. These sources are pinned while the controller is active. This trial must not be expanded merely because training CE falls; compare unfiltered held-out geometry and retrieve identity before any promotion.
