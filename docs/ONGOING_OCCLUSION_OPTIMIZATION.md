## 下一轮：候选条件的更新可靠性头

新增 `UpdateQualityHead`：输入当前 256 维 latent、object/context latent、
已有 state、16 个深度 support、当前修正量和候选 delta。观察与候选分别
编码，并加入逐元素交互；输出有害更新概率和连续误差改善量。冻结该头
参数时，候选 delta 的梯度仍保留。它不调用 FP，也不读取手标注。

先固定 R1K1 teacher，收集 official **train** 中 2,048 个真实连续片段：
1,536 train / 256 calibration / 256 audit，按物理序列划分互不重叠。
每片段 8 帧 burn-in + 32 帧监督，保存 65,536 个当前观测及五个候选
（原 delta 的 -1、0、0.5、1、1.5 倍）。保存 base/candidate/GT pose、
ADD/ADD-S 连续值、旋转/中心误差、改善量及标签，误差单位明确为直径
归一化或 degree/mm。GT 仅用于训练标签与 loss。

可靠性头最多训练 2,000 步，在 calibration 中按**原始 LIP 候选**的 Brier
选择权重，再一次性检查 audit；不能用容易区分的反向候选排序代替原始
更新安全性的判断。接入资格预先要求 calibration 和 audit 都满足：

- 原始候选 harmful AUROC >=0.75；
- Brier 小于固定训练集先验预测的 90%；
- FPR <=5% 时 harmful recall >=20%；
- 同一观测内候选排序准确率 >=65%，只计误差差距 >0.005d 的候选对。

这些只是可靠性头的中间检查。即使通过，也必须再做实际闭环消融，检查
强遮挡收益、总体退化、恢复能力、运行速度和独立非 GT 初始化协议，才
能判断网络结构是否进步。未通过时不会强行接入主模型。

## 空间关键帧记忆：已实现并启动配对训练

`SpatialRKTracker` 保留 R1K1 的原有路径，并增加一条空间记忆残差：

- 仍使用 ResNet50 layer3、geometry CNN、两层 spatial cross-attention、
  四层 causal temporal Transformer 和 256 维 latent；主时序 source 仍为
  17 tokens、最近窗口仍为 8 帧。
- 四个关键帧保留 spatial fusion 后、4×4 pooling 前的 **14×14 特征**，
  最多读取 784 个旧空间 tokens；原来的 context-token 记忆保留。
- keyframe 的 source 特征与 crop/pose 记录不变。空间位置采用与原
  source metadata 一致的 cell-center 约定，不宣称是卷积感受野中心。
- 新 attention 以当前 object latent 查询旧空间特征，加入相对旋转、
  中心位移/直径、crop 内参比例/偏移和时间差的条件嵌入。它是 pose-
  conditioned attention，不是已经证明正确的几何特征 warp。
- 新输出投影为零初始化，gated residual 从零开始。只读当前时刻之前、
  最近 8 帧之外且不超过 64 帧、同一 stream 的关键帧。
- 使用独立 cache contract；crop/缓存身份、detach、校正保留与重定位清空
  均有检查。未加载、未调用上述不合格可靠性头，也不调用 FP。

对照为继续训练的 R1K1；实验组在同一父权重上增加空间记忆。两组都训练
原 R1K1 的可训练小模块，旧 backbone/geometry/spatial fusion/temporal
encoder/pose head 保持冻结，新参数仅出现在实验组。两组各四张 H20，
每步 64 个片段、8 burn-in + **48 帧监督**、1,000 步、seed 42、同一份
64,000 项采样清单。旧参数 LR 与新参数 LR 分别为 1e-5 和 5e-5。
全部 6,400 条训练流及原来的 20 个训练 target object IDs 均仍可采样。

实际通过 41 项测试；两条真实训练片段的 112 帧在 FP32 和 BF16 下，
新分支初始输出都与对照逐位一致。另对照归档父模型的两条完整验证流、
148 帧逐位一致。该检查是明确的有界起点检查，不冒充重跑全量父模型。
单卡完整 unroll、四卡 DDP、四个 rank 的严格恢复检查均通过。

训练后会自动跑同样的 s0 val 320 流 / 23,200 帧，使用已固定的带噪 GT
首帧文件，输出空间组与继续训练对照、与未继续训练的 R1K1 父权重的
配对区间。新结构尚无完成后的精度结论，不能因新增模块或测试通过就

## CAD 坐标对齐读取：独立原型已通过有界检查

## 冻结位姿头的表达检查与直接残差架构

## 待验证结构：保留位姿参考的观测条件反馈

## 可学习参考写入：实现和配对预检

最近使用观测的时间戳，防止未来参考或跨 lane 状态泄漏。外部校正
