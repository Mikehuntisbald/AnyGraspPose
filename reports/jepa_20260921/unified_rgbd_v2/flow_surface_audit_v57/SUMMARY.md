## 1. 二维匹配变好并不保证沿视线的深度准确

在10度参考扰动的重遮挡子集中，直接从预测flow做PnP几何拟合，表面对应略好，
深度反而大幅变差。把同一JEPA预测的深度加入3D几何拟合，才恢复到较好的尺度。
所有方法在不可用位置回退到原V56，下面统计全部原始目标，没有按预测置信度
筛选评分像素；另外保留覆盖率和拟合接受率。

| 恢复方式 | 真实目标XYZ / 深度 mm | CAD代理XYZ / 深度 mm |
|---|---:|---:|
| V56 原输出 | 8.695 / 7.617 | 8.846 / 9.052 |
| 预测flow + RGB几何拟合 | 7.952 / 29.849 | 8.226 / 32.624 |
| 预测flow + 恢复深度 + 3D拟合 | 6.547 / 8.626 | 6.616 / 7.426 |
| 再融合预测可见性加权的测量深度 | 6.807 / 8.413 | 7.179 / 9.268 |

这证明预测对应与恢复深度中存在互补信息，但不能据此采用刚性后处理：真实
深度仍回退，60度下也未通过。60度重遮挡的CAD代理XYZ/深度从35.376/14.673
变为36.039/16.348mm（flow+恢复深度）。本轮PnP/3D拟合仅用于信息诊断，
没有新增推理主路径、位姿训练或位姿评测。

## 2. 当前点可见性分数不足以可靠选择真实测量

10度组1489个有明确可见性标签的点中有648个可见点；点可见性AUROC为0.624，
可见/不可见均分0.48930/0.48857。60度组AUROC为0.542。全部分数低于0.5，
所以硬阈值会使测量锚点全部消失。仅调整阈值不能宣称修好了质量辨别。

还纠正了诊断实现中的语义混用：旧`evidence_logits`监督的是patch可见面积
比例，不能直接当作某个CAD点的可见概率。r3/r4改用点可见性的连续权重、
深度一致性衰减及鲁棒3D拟合，10度组有1295个测量锚点实际贡献，平均测量
比例约0.30；结果仍未超过恢复深度单独拟合，不能简单强行加入更多传感器点。

代码中的点可见性头主要消费CAD描述子和匹配到的JEPA表征，未直接拼入对应的
原始观测描述子/测量差异。补全表征与真实观测可信度应区分；这属于接下来
需要验证的设计原因，AUROC本身不能证明唯一根因。

## 3. 两类深度监督确实不同

直接用GT位姿渲染、完全跳过任何拟合，在10度组重遮挡真实目标上的深度差
仍为10.234mm；60度组为9.875mm。CAD代理目标的差则严格为0。
这是CAD渲染与原始传感器目标的实测差异，不是对网络的下界证明，也未确定
来自标注、模型形状、校准还是传感器误差。不能把真实深度强行改成CAD监督，
也不能只看CAD代理的零误差便宣称监督与物理场景完全吻合。

固定potted-meat-can样本进一步检查：原始标注与pose缓存完全一致，原始坐标/
中心坐标投影最大差0.00012mm，几何mesh与纹理mesh边界差小于0.000002mm。
排除了该样本的中心变换或缓存错位。相机Z插值自洽误差0.00012mm；像素重投影
平均0.00044px、最大0.04645px，射线XYZ最大误差0.05213mm。最初严格数值门限
0.002px/0.01mm未通过，这一失败原样记录，未把阈值放宽后宣称通过。
同一样本可见表面的真实深度却平均比CAD深13.569mm，不能据当前检查确定原因。
